Esta aplicación es una interfaz desarrollada en Flutter para mostrar eventos universitarios en una pantalla principal. La app presenta un encabezado con imagen y texto descriptivo, seguido por filtros por categoría para visualizar solo los eventos que interesan al usuario. Cada evento se muestra en una tarjeta con información como nombre, fecha, hora, lugar, cupo y categoría.

La funcionalidad principal es permitir que el usuario navegue entre distintos tipos de actividades del campus, como académicos, deportivos, culturales, tecnológicos o talleres, y ver solo los eventos correspondientes al filtro seleccionado. También cuenta con una acción visual para indicar interés en un evento, mostrando una confirmación rápida al usuario.

La app está organizada para separar la lógica de la pantalla, los datos de eventos, el tema visual y los widgets reutilizables. Se ejecuta como una aplicación Flutter normal y puede abrirse con Flutter SDK usando los comandos de instalación y ejecución estándar. El proyecto está pensado como una práctica de diseño y lógica de interfaz para una app de eventos universitarios.
